Workflow

Message 0 is never hidden, whatever this is set to. The pinned tail keeps the chat from going blank the moment a summary is generated, and leaves the model some verbatim recent context.

Coming from the built-in Summarize

On a chat the built-in already summarised, {{recall}} resolves to that summary until you generate your first, and it seeds that first generation so Recall revises it instead of writing a new one from scratch. Read-only, and it does not need the built-in to be enabled — the text lives in the chat file. This is also what makes an old chat with already-hidden messages safe to summarise without unhiding everything first.

Context nudge

In tokens, measured against the last prompt actually sent. Leave at 0 to track 80% of the current context limit. Fires once per crossing, then stays quiet until a summary brings usage back down.

Advanced

Two settings, because one number cannot do both jobs. The reserve is how much context room to hold back when budgeting the buffer — set it high and summarization starts refusing chats it could handle. The output budget is the generation limit sent to the API. On OpenAI-compatible sources that budget covers reasoning and visible output together, which makes it the only thing stopping a model that thinks without end; on Claude sources at high reasoning effort, a low budget starves the summary instead.

Wraps the previous summary in the buffer. The prompt branches on whether this block is empty, so it is always emitted — an empty one included. Match whatever your preset uses.
